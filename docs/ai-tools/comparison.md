## 工具说明

- 工具名称前缀：【CLI】表示命令行工具、【IDE】表示集成开发环境、【插件】表示编辑器插件
- 平台支持：
  - CLI：一般都是全平台支持（Windows、macOS、Linux）
  - IDE：一般兼容 Windows、macOS，部分 IDE 支持 Linux
  - 插件：主要兼容 VS Code，部分支持 JetBrains 系列
- 支持 JetBrains 的插件，一般体验都比 VS Code 要差一点
- 标注的模型，按同系列最好的标注。即：同时支持 `GPT-5` `GPT-5.1` 则直接标注 `GPT-5.1` 
- 不论是 IDE 还是插件，基本上常用的 Agent、MCP、rules 都支持，各个工具主要功能差异不大
- 有的工具我注册很早，送的 Credits 比较高，可能与实际存在偏差
